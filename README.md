# DreamDrive Motors

DreamDrive Motors is a Python project that simulates a car dealership management system.

I made this project to practice Python and learn how different concepts can work together in a larger program. The program lets you manage cars, customers, employees, and sales from a simple menu.

## What the program can do

* Add cars to the dealership
* View all cars
* View cars that are still available
* Search for a car by its brand or model
* Add and view customers
* Add and view employees
* Fire employees
* Sell cars to customers
* View the sales history
* View dealership statistics
* Automatically create IDs for cars, customers, and employees

## What I learned

While making this project, I practiced:

* Classes and objects
* Object-Oriented Programming (OOP)
* Functions and methods
* Lists and dictionaries
* Loops
* Conditional statements
* `try` and `except`
* Input validation
* Searching through lists
* Connecting different objects together

The project has four main classes: `Car`, `Customer`, `Employee`, and `Dealership`.

The `Dealership` class manages the cars, customers, employees, and sales. When a car is sold, the program marks it as unavailable, adds it to the customer's purchased cars, and records the sale.



## About the project

This is a learning project, so it is not meant to be a real dealership system. I built it mainly to get better at Python and to see how much I could do by combining the concepts I had learned.

I also plan to improve it in the future by adding things like saving data to files, a database, better reports, and possibly a graphical interface.
